# AI-Hackathon---AI-PC-Builder
## Overview
AI PC Builder is an intelligent system that helps users build compatible PCs based on budget and purpose using Artificial Intelligence.

The system uses:
- FastAPI backend
- Figma frontend
- Ollama LLM (llama3 version of LLM models)
- LangChain
- Compatibility checking
- AI recommendations
- Budget Optimization
- AI PC Installation Guide
- Multi-purpose recommendation system

## AI Features

- AI-generated PC recommendations
- Budget optimization
- Compatibility checker
- AI explanation for selected components
- Installation guide generation
- Beginner-friendly UI

## Technologies Used

- Python
- FastAPI
- Figma
- Ollama
- LangChain
- JSON Database

## System Requirements

- Python 3.10+
- Ollama installed
- Internet connection

## Installation
### 1. Clone Repository

```bash
git clone YOUR_GITHUB_LINK
```

### 2. Install Dependencies

```bash
pip install -r Requirements of Run Code.txt
```

### 3. Start Ollama

```bash
ollama run llama3
```

### 4. Run FastAPI Server

```bash
uvicorn main:app --reload
```

## AI Workflow

User Input → FastAPI Backend → Compatibility Engine → LLM Recommendation → Build Generation → Frontend Display
